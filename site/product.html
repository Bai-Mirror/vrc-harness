一次制作

从说明目标，到检查和确认

每个阶段都能看到当前进度和下一步。

  1. 你

    说明目标

    管理自己拥有的素材，用对话或表单说明想要的结果。

  2. AI 执行方

    执行制作

    用你自己的 API 密钥驱动模型，按角色自动路由，按实际用量计费；在沙箱里运行。

  3. Harness

    检查与冻结

    流程定义、工具与知识按哈希冻结；每一步由独立观测给出判定；失败时带着证据有限次数地返工。

  4. 你

    确认关键改动

    需要你决定时会暂停。确认后，制作才继续。

已实现

开发版已实现的功能

以下功能已在开发版中实现。界面图取自开发中的版本，其中的项目与素材均为演示数据，最终发布版本可能不同。

01 · 说明目标

用对话或表单说明目标

新建项目时描述想要的头像，或从素材库挑选；已有的 VCC/VPM 工程可以接管进来。项目列表按进行中、等你处理、未开始、已结束筛选，每张卡片都写着下一步或需要你决定的事。

  • 对话或表单：两种方式说明目标，由你选。
  • 接管已有工程：适用于 VRChat 头像，兼容 VCC/VPM 工程。
  • 你的素材：目标围绕你自己拥有的素材来定。

02 · 正式流程

16 个阶段，每一步都有判定

从检查素材、确认方案、准备制作环境，到装配服装、调整颜色、制作换装菜单、效果检查、性能优化，最后整理交付包，一次改模按正式流程推进；跑起来之后在项目的「运行监视」里看。

  • 检查素材
  • 确认制作方案
  • 准备制作环境
  • 准备工程
  • 设计脸型候选
  • 调整脸型
  • 装配服装
  • 调整颜色
  • 制作换装菜单
  • 首次构建
  • 首次效果检查
  • 性能优化
  • 最终构建
  • 最终效果与贴合检查
  • 性能验收
  • 整理交付包
  • 按哈希冻结：流程定义、工具与知识在开工时冻结。
  • 独立判定：每一步由独立观测给出判定，而不是 AI 自称完成。
  • 有限返工：失败时带着证据有限次数地返工。
  • 人工闸门：关键节点请你批准。

03 · 项目工作区

项目记忆：换模型、重启、开新对话，进度都在

每个项目有自己的工作区：设计目标、素材选择、审美对话、运行监视。进度属于项目，不属于某一次对话。

  • 项目记忆：切换模型、重启、开新对话都不丢进度。
  • 双界面：GUI（桌面窗口）与 TUI（终端），共用同一个本地 Runtime。

04 · 素材

BOOTH 已购素材只建索引，需要时才取文件

把你已经拥有的素材登记进来：BOOTH 云端素材只同步索引、使用时下载；本地零散素材只记录原文件位置。

  • 只建索引：BOOTH 已购素材只建索引，项目需要时才按需获取文件。
  • 本地素材：本地素材也可登记。

05 · AI 执行方与能力包

接入你自己的 API 密钥

核心管理里列出接入的执行方——经 pi 用你自己的 API 密钥驱动模型，按角色自动路由、按实际用量计费。知识与工具由 Harness 管理版本：新流程固定当前版本，已在运行的项目不会被更新悄悄改变。

  • AI 执行方：经 pi 用你自己的 API 密钥驱动模型，按角色自动路由。本版接入 DeepSeek；OpenAI、Anthropic、Google 的 API 密钥仍在开发，尚未开放。本版不支持订阅制 AI 客户端的接入。
  • 能力包：受管的知识与工具包，由服务端签名发布；客户端验签后在安全点更新，旧流程保持冻结。

06 · 环境与后台服务

沙箱、环境依赖与后台服务

设置页里有后台服务（调度状态、安全点暂停、Runtime 与数据目录）、配置管理、协作学习开关，以及环境依赖清单——包括执行沙箱所需的系统组件、Unity 编辑器与 VPM CLI。

  • 沙箱：执行方在沙箱里运行，工作区以外的写入被阻止。
  • 本地 Runtime：GUI 与 TUI 共用同一个本地 Runtime。
  • 安全点：能力包在安全点更新，旧流程保持冻结。

安全边界

执行方能做什么，边界是明确的

AI 执行方负责做事；它够不到的地方，同样是设计的一部分。

01

沙箱运行

执行方在沙箱里运行。

02

工作区以外不可写

工作区以外的写入被阻止。执行方（AI）运行时能读取你电脑上的文件，也能联网；这条限制的只是写入，不是读取或联网（见已知限制）。

03

控制接口不可见

Windows 上执行方在 Low 完整性下运行时，Harness 的控制接口、配置与 BOOTH 会话对执行方不可见，执行方无法替你批准；部分 Unity 步骤会回退为不做额外隔离，那种情况下这条不成立（见已知限制）。

协作学习 自愿加入

产品改进数据默认关闭。明确加入后，按授权类别回传结构化报告，可随时退出；素材、模型 Key 和自由文本不会随默认报告上传。接收服务已开放，并完成授权、归属与撤回检查；收到报告不等于自动采用或公开发布。服务器保存 90 天后自动删除；删除或撤回后，数据在运营者的备份中最多再保留 90 天。

规划中

规划中，尚未实现

本版只提供 Windows 版；Linux 版稍后提供。以下功能仍在规划，何时提供以后续更新为准。更完整的未做清单见已知限制。

每一项都标注为规划中；在实现并经过判定之前，不会出现在上面的「已实现」里。

  • 规划中3D 实时预览制作过程中实时查看改动
  • 规划中形态键滑杆面板在产品内直接拖动形态键调整脸型
  • 规划中圈画改脸在预览图上圈出区域，换算成形态键候选
  • 规划中菜单预览与编辑游戏轮盘菜单的预览、编排与写回工程
  • 规划中多语言界面中 / 日 / 英 i18n 框架
  • 规划中统一素材库与分步选材向导BOOTH 与本地素材合成一个图库，按步骤选材
  • 规划中素材缓存管理全量缓存、更新检查与本地空间管理
  • 规划中Linux 版本版只提供 Windows，Linux 稍后

dev.0.1（0.1.0-dev.1）是首个公开技术预览版，只提供 Windows，安装包尚未公开。下载页写了安装与放行步骤，已知限制逐条列出本版还没做到的部分。真实完整自动改模交付仍未成功，官方知识与工具更新已开放不代表应用安装包已经发布。
