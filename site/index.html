我想解决的问题

改模的门槛，不该由你一个人扛

把角色改成自己想要的样子，本来要跨过好几道坎。

01

要学的东西太多

给自己的角色换衣服、换发型、改脸，通常要学 Unity、学 Blender，还要搞懂一堆插件。真正的门槛不是不会点按钮，而是不知道哪一步会出错。

02

AI 省下的是注意力，不是专业知识

AI 已经能帮你操作这些工具，但你仍然得知道该让它做什么、做得对不对。省下来的是动手的注意力，专业知识还得你自己补。

03

Harness 把专业知识装进产品

怎么挑素材、怎么装配、哪里容易出错、做完怎么检查——这些规则由 Harness 管理。你只需要说出想要的样子。

怎么用

四步，从素材到你的角色

制作由 Harness 驱动 Unity 与 Blender 完成，你不需要自己改工程。

  1. 第 1 步

    准备 AI

    注册一个 DeepSeek API 账号，把密钥填进 Harness。模型按实际用量计费，花销记在你自己的账号上。

  2. 第 2 步

    安装 Harness

    下载 Windows 版并安装。有 BOOTH 账号就登录一次，Harness 能找到你买过的素材；本地整理好的素材也可以直接登记。

  3. 第 3 步

    新建项目，说明想要的样子

    从你拥有的素材里挑，或直接导入整理好的素材文件夹 / 压缩包；再用一句话或几张参考图说明想要的效果。

  4. 第 4 步

    等 AI 做完，关键处由你确认

    Harness 自动装配、逐项检查；需要你决定的地方会停下来等你确认，完成后引导你上传到 VRChat。

我做了什么

不是 AI 说做完了，而是有判定说做完了

把「AI 能动手」变成「结果可以被检查」，是 Harness 真正做的事。

核心口径

AI 负责执行，判定不由它自己下

每一步做完，都由独立的观测给出判定：通过了什么、哪里没过、失败了几次、返工后变成什么样，都留下记录。AI 不能自己宣布完成，你也不需要凭它的说法判断对错。

01

独立判定

每一步由独立观测给出判定，而不是由执行方自称完成。没通过时记录问题和返工结果，方便继续处理。

02

开工后沿用同一套规则

开始制作时会固定使用的流程、工具和知识版本。中途更新不会悄悄改变这个项目。

03

关键改动由你决定

需要批准的地方会暂停制作，等你确认后再继续。

04

执行方在受限环境里工作

制作在受控环境里进行；Windows 上执行方在 Low 完整性下运行时，Harness 的控制接口、配置与素材会话对执行方不可见，它也无法替你批准。部分 Unity 步骤会回退为不做额外隔离（见已知限制），那种情况下这条不成立。

05

进度属于项目，不属于对话

换模型、重启、开新对话，项目进度和已确认的事项都还在——它们存在本地的数据目录里，不在某一次对话里。

06

知识与工具也管版本

内置能力包由 Harness 统一管理：更新由服务端签名发布，客户端验签后在安全点生效。

这些机制的逐项说明和界面截图在产品介绍里。
