Harness dev.0.1（0.1.0-dev.1）

下载与安装（Windows）

本版只提供 Windows 版，Linux 版稍后提供。下面是安装前要准备的东西、安装步骤，以及未签名安装包会遇到的系统提示怎么处理。

下载尚未开放

安装包仍在收口与验证，按钮保持不可用。开放下载前会先通过最终授权，届时一并公布文件名、大小与 SHA-256 校验值。可先阅读已知限制了解本版还不能保证的部分。

Windows 安装包

64 位安装程序，文件名 Harness_0.1.0-dev.1_x64-setup.exe。

安装包没有系统发布者签名，因此 Windows SmartScreen 与部分安全软件会先拦一下；处理办法见下面的安装步骤。

Linux 版

稍后提供，不在 dev.0.1 的范围内。本页只写 Windows 的安装步骤。

Linux 上的开发与回归测试照常进行，只是本版不提供安装包。

安装步骤

未签名的安装包，怎么装下去

安装包没有购买代码签名证书，Windows 和国内安全软件都会把它当成「未知发布者」。这不是文件损坏，按下面的步骤明确放行即可。

01

先对一下来源

只从 harness.nymiro.moe 下载，并核对公布的文件大小与 SHA-256。来源对不上就不要运行。

02

通过 SmartScreen 提示

双击安装包后，如果出现「Windows 已保护你的电脑」，点更多信息，确认应用是 Harness、发布者为「未知发布者」，再点仍要运行。

03

给安全软件放行

火绒、360、腾讯电脑管家等可能拦截或隔离未签名的安装包。先在安全软件的信任区 / 白名单里加入安装包，安装后再把 Harness 的安装目录一起加入，然后重新运行安装包。

04

按向导装完

按向导完成安装，装完后启动 Harness，第一次打开会进入首次配置。

不同版本的安全软件提示文字不一样，本页写的是处理原则。安装程序本身还没有用真人双击的方式装过，也没有开着安全软件实测过；已经自动验证的是静默安装：新装、同版本重装、卸载、安装位置回退与静默卸载后清理位置记录。没有实测的部分一并记在已知限制里。

安装前准备

系统与组件

桌面包自带 Node 运行时；其余组件在首次配置的「环境依赖」里逐项检查，缺少的会列出安装方式。

Windows

Windows 10 / 11 64 位。首次安装依赖需要 winget（随 Windows 自带的应用安装程序）。系统过旧或没有 winget 时，首次配置会把缺的软件列出来，并提示先更新 Windows 或安装「应用安装程序」；设置类项目照常进行。

Unity

制作工程与构建需要 Unity 编辑器。推荐用 Unity Hub 安装，并登录一个 Unity 账号激活免费的 Personal 许可证。

随包组件

Harness 的 Windows 辅助程序随桌面版提供，负责监管执行单元并划定写边界，不需要单独安装。

通用工具

git（工程追溯）、Python 3（内置阶段工具）、7-Zip（交付打包与校验）。缺哪一项，首次配置会给出安装方式，在 winget 可用时可以自动完成。

开始前

连接 AI、素材与数据

连接 AI（只用 API）

本版接入 DeepSeek API：注册后把 API 密钥填进 Harness，按实际用量在你自己的账号上计费。OpenAI、Anthropic、Google 的 API 密钥仍在开发，尚未开放。本版不支持订阅制 AI 客户端的接入。

授权素材，保留原件

使用你有权使用的头像和素材，授权对应目录。制作使用副本，请保留原件和已接受的产物。有 BOOTH 账号就登录一次，Harness 会为你买过的素材建索引；本地整理好的素材也可以登记。

决定是否贡献数据

产品改进数据默认关闭。你可以在设置中明确加入或退出；不加入也能使用本地制作。加入后按授权类别回传结构化报告，可随时退出。服务器保存 90 天后自动删除；删除或撤回后，数据在运营者的备份中最多再保留 90 天。

早期测试边界

这是首个公开技术预览版，功能与质量都还没到最终形态。

  • 完整改模交付仍在验证：原图到交付包的端到端产出、两套真实头像的完整交付尚未完成，本版不能保证稳定自动改模。
  • 本版只提供 Windows，且安装包未签名；Linux 版稍后提供。
  • 产品内的 3D 实时预览、形态键滑杆面板、圈画改脸、菜单预览与编辑都还没有实现。
