# 捏脸：凹凸与褶皱的归因和局部修复

## 捏完脸上起凹凸：先否掉两条错路，再用指标定位

**职责**：用户说捏脸让网格出现凹凸纹理、影响观感，或在 cavity／toon 渲染里看到褶皱棱线时，找出真正原因。

现行接受约定：下文指标归零是修复目标，不是中止制作的条件。每项质量发现记录原版同状态读数、毫米/像素可见性与同机位特写；明显可见可针对性修一次，剩余和不确定发现交用户看图判断并继续到待接受。技术性失败才计入同类三次停止；不调用额外收费评审来替用户接受。

**权威输入**：厂商原版 basis 与「basis＋捏脸位移」两组坐标，用同一套面表计算；一块全程没被捏脸动过的对照区（例如额头）。

**决策边界**：
- 先否掉错路一「自定义法线陈旧」：先量厂商自定义法线与几何法线的夹角。夹角大（>20° 量级）说明法线是手绘的、与几何解耦，把法线跟随几何旋转必然无效；夹角小才值得跟随。
- 先否掉错路二「表面被拉皱」：比较捏脸前后逐顶点 Laplacian（umbrella）幅值。整体曲率没有变差，就别做全局平滑，那只会把捏脸抹平。
- 定位用一组指标，前后两组坐标同一面表：新增网格自交（`BVHTree.FromPolygons(...).overlap(self)`，剔掉共顶点的相邻面对）；面法线转角；面积比 `A_after / A_before`；法线翻转（转角 >90°）；相邻面二面角变化 Δdihedral（每条被两个面共用的边）；位移场高频 `|Laplacian(D)|`（按边邻接算 umbrella）。前几项只量「面自己」转了多少、塌了多少、穿没穿，测不出眼睑上那种分层横向明暗条带（相邻面之间的断阶），所以后两项必须加。
- 阈值拿对照区定：对照区的指标几乎为零时，阈值取在对照与问题带之间。
- 各指标会落在同一条带上，按高度分段统计就能定位。逐键归因：只开一个键，重跑同一组指标。负值（反向线性外插，厂商没设计过的区间）与满幅（±1）的键优先查。

**禁止**：没有对照区就用统计表下结论；把法线跟随或全局平滑当默认修法。

**产出**：分段指标表（含对照区）、逐键归因表。

**验证**：对照区的指标接近零；问题带与肇事键能对上渲图里看到的褶皱位置。

**升级给人**：肇事键正是委托方定形时刻意拉高的键时，说明修复会带来的造型扰动，请用户选择。

## 捏脸凹凸的修法：只在出事邻域平滑位移场

**职责**：在不丢捏脸的前提下，消除局部挤瘪与卡片层间互穿。

**权威输入**：归因得到的问题带与种子面；捏脸位移场 D。

**决策边界**：原理是相邻卡片层拿到了不同的位移，而层间距只有零点几毫米，位移差一大就互穿。所以平滑的是位移场，不是几何；而且只在出事的邻域里平滑（修，不是重置）。
1. 种子：新增自交面 ∪ 转角超标的面 ∪ 面积比过低的面，取其全部顶点；再并入 `|Laplacian(D)|` 超标的顶点与 Δdihedral 超标的边的顶点。
2. 影响权重：v 到最近种子的 3D 距离 d，`w = smoothstep(1 − d/r_blend)`，`d ≥ r_blend` 时为 0。
3. 平滑：`D̃(v) = Σ_j exp(−(d_ij/(0.6·r_smooth))²)·D(j) / Σ w`，邻域用 3D KDTree 半径 `r_smooth`，不用网格连通性（必须跨过互不相连的卡片层，否则层间根本同步不了）。
4. `D(v) ← D(v)·(1−w) + D̃(v)·w`，迭代 1–3 轮。
参数要扫出来：判据是硬指标归零、且对捏脸的扰动最小。半径超过卡片间距的尺度后会互相带偏，再大不会更好。达不到全零时，优先收小 `r_blend`（少动点），而不是加轮数（对同一批点反复平滑，扰动涨得快）。

**禁止**：全局平滑；整体重置网格；只报数值归零就宣布消除。

**产出**：扫参表（每组参数的各项指标与扰动 max／p99／mean）、选用参数、修后指标表。

**验证**：新增自交、转角超标、面积塌陷三项归零；总自交数不高于厂商原版（否则只是把问题搬了个地方）；对照区的 Δdihedral 超标边数仍为 0（平滑的混合边界会给干净区域带进一点高频，超标说明 `r_blend` 铺得太开）；原版／未修／已修三联图同机位、同光、同材质，交第二个模型证伪，它指出的阈值以下的残留要报。

**升级给人**：修后扰动明显改变造型，或评审仍指出残留。
