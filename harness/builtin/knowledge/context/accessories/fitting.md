# 配饰装位阶段：环形件贴合与参照面

## 环形配饰的贴合：从几何求解，至少两条判据

**职责**：戒指、腕饰、发箍式头饰、项链、脚环、耳环这类「一个环套在一段肢体上」的件，算出孔轴、孔心、内径和滚转，不手填欧拉角。

**原理**：人形骨的局部坐标轴由素体作者随意确定，八根手指骨各不相同；手填必然是八组魔数，换个素体全部报废（戒指填零旋转是平躺在手背上，填 90° 只是换个方向躺着）。装位表只留「套在哪段骨、套在这段的百分之几处」和两个默认 1.0 的微调系数，其余从几何推。

**步骤**：
1. 探形状：按骨权重给顶点分组，逐组计算，不在整块顶点云上算（吊坠挂在孔轴方向上时，整体统计没有一根轴穿过空心）。
2. 孔轴与孔心：逐组逐轴求「最大空圆」，即平面内离所有顶点都最远的点；爬山最大化最小半径，并夹在包围盒内。真判据是孔心被四面包住：附近顶点按角度分扇区，每个扇区都有料。
3. 选佩戴孔：轴向取信号最强的组，在该轴上逐组复测，取「通过扇区判据、且半径不小于最大环一定比例」的组里最小的那个，以挡住装饰件上的小孔。
4. 内径：从素体网格实测肢体粗细。取绑在这段骨上、落在目标位置附近一薄片里的顶点，量到骨轴的距离取高分位，用绑定姿势计算；再乘贴身或宽松的余量系数。
5. 滚转：吊坠、蝴蝶结、缎带在环的哪一侧，那一侧朝外；参照取径向明显凸出环外的顶点。对手指，「朝外」是手背方向，用「指节横排 × 指向」的叉乘定法向，符号按左右手分别验证。

**判据至少两条**：①孔轴对齐——肢体轴线到孔心的距离小于内半径、轴线与孔轴夹角小于阈值，表示套住了；②正面朝向——有正面的部件（如宝石）质心在外侧法向上的投影为正，表示没戴反。只有①管不了戴反，戴正与戴反的读数完全一样。

**禁止**：用包围盒最短边当孔轴；用质心或包围盒中心当孔心；用相邻骨间距当肢体粗细；用四指弯曲量求和当掌心方向。

**产出**：每件的孔轴、孔心、内径、滚转与两条判据读数。

**验证**：两条判据都通过后，再看顺轴图与侧视图。

**升级**：探针报找不到环状结构；或装饰朝轴的哪一端张开这类几何推不出的资产语义，出两个方向的对比图交用户选，结果写回装位表的 `flare`（±1）。

**证据说明**：步骤与判据形态来自一个工程里的戒指、腕饰、头饰三件（同一算法通吃）。具体阈值（夹角 12°、半径比例 60%、97 分位、余量 1.05/1.10、径向 1.5 倍、12 扇区）是该工程的标定值，属候选，换件时复核。

## 装位参照面：埋深看渲染出的表面，挂位按件类选面

**职责**：确定配饰「埋多深」和「贴在哪个面上」。

**原理**：
- 要合理埋入头中、与头连成一体的件（如兽耳），参照面是渲染出来的发丝表面，不是颅骨包围盒的顶。两者可以相差 3 cm 以上：按颅顶埋 3 cm，实际仍浮在发丝上；评审说「悬浮」和日志说「埋深 3 cm」可以同时为真，因为量的是两个面。
- 就地量：在配饰接触点附近取一小片（例如半径 3 cm）取高分位，不在整颗头上取最高点——那会咬到呆毛尖，照它埋会把配饰顶到发面之上，越修越糟。左右对称件左右各量一次再取平均。
- 可穿戴件按类型落在有物理含义的面上，而不是一组偏移量：抄来的坐标换个素体就废，面才跟着素体走。悬浮面板类贴头部包围盒前表面、下缘约在眼睛高度；环形件套骨、环心在骨轴上，并先看那一圈被什么盖着（颈饰被衣领盖住时要沿颈骨下移、前移才露出来）；抱持类（怀里、背后的玩偶）包围盒中心落在该高度躯干的前表面，大件再横向偏向一侧。这些都是顶端对齐而不是中心对齐：怀抱物顶端齐下巴，包裹物顶端齐头顶。

**禁止**：拿整颗头的高分位点当发面；把别的素体上的装位坐标直接抄过来。

**产出**：每件的参照面类型与实测读数。

**验证**：与头同框的多视图里接触部位不悬浮、不穿出；数值读数与图一致。

**升级**：参照面被衣物或头发盖住、无法判断时，强制显示被遮物并渲一张特写确认；仍不能定的交用户。

**证据说明**：参照面分类只有四件样本，是经验不是定理；读数与偏移见质量记忆的候选条目。

## 作者已定的朝向、尺寸与形状键：只补作者没给的

**职责**：区分哪些量该计算、哪些量该沿用作者的设定。

**原则**：几何拟合只补作者没给的信息。
- 朝向：厂商预制体根的 `localRotation` 是单位阵、且件的环轴正好是素体 +Y，说明作者已在素体站姿空间里摆好朝向。再跑「把装饰转到朝外」的拟合会把整个头饰偏航十几度、把侧面的大蝴蝶结拧到正前方。头顶件沿用素体朝向（最多加一个显式俯仰角），只算位置：把件自身的环心钉到「头部实测中心＋偏移」。
- 尺寸：作者专门为这台素体做的件不缩放，它的绝对坐标就是答案。做给别的参考素体的通用件先等比缩放：从厂商角色渲染图量一个作者认可的相对比例（如耳展 ÷ 脸宽），用本素体实测头宽换算 `k = 目标比例 × 头宽 ÷ 当前展宽`；缩放不动点取头中心（配饰一边变小一边朝头收拢），每次按「目标 ÷ 当前」重算以保持幂等。
- 形状键：商品说明写明可用形状键调整角度或尺寸时，贴合优先用形状键而不用缩放（缩放会把缎带、串珠一起放大，比例就散了）。权重算不出来，因为几何探针读的是绑定姿势顶点、看不见形状键；只能用渲染图夹：0 与 100 各出一张，按评审指认的方向取中间值，写回装位表。
- 手填偏移写在素体自身坐标系里，再换算到挂点局部；直接把「x=右、y=上」写进骨局部空间，倾斜方向会被摆反。
- 镜像成对件（`localScale` 某轴为 −1）：装位算出的是大小，符号从预制体原型取回（`PrefabUtility.GetCorrespondingObjectFromSource`）；拼旋转时方向向量也先乘上符号，否则孔轴与装饰朝向两个约束会在镜像那一维上解反。

**禁止**：对作者已定的量再做一次几何拟合；用 `Vector3.one * s` 覆盖镜像件的缩放。

**产出**：装位表里每件注明哪些量沿用作者、哪些量由计算得出。

**验证**：左右成对件的 `localPosition` 的 x 反号、`localEulerAngles.y` 互补到 360°；缩放后第二次运行系数为 1.000。

**升级**：展示图与预制体摆法不一致时，交用户确认以哪个为准。

**证据说明**：来自单一工程的头饰、兽耳、腕饰，属候选做法。
