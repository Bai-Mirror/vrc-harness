# 形态键清单与实测的案例

## 选形态键先量强度，再看名字：同方向的键强度能差一倍，名字也可能与效果相反

- **症状**：捏脸候选之间「眼尾上挑与下垂」的差异渲出来几乎看不出。
- **机制**：
  1. 名为「吊り目」的 `eyelid_turi2` 实测眼尾倾斜 −0.00100（是下垂）；看图时却被读作「眼尾上翘变尖」，两种方法结论相反，未解决。
  2. 同一方向厂商给了多条键，强度差一倍以上：最强下垂 `eyelid_tare2` −0.00224，最强上挑 `eyelid_turi1` +0.00223，而候选表里用来上挑的 `eyelid_tail_up` 只有 +0.00124，给值 15–30 时几乎等于没生效。
- **判据**：逐键探针：全零基准加每个键单独拉到 100，同机位渲图并量眼尾倾斜（单位米，正为眼尾相对眼头抬起）；图不能是纯色，差异应只出现在眼眉区域。
- **当时的修法**（人工作业，供理解机制）：做差异化时挑强度足够、两种方法结论一致的键（该例上挑改用 `eyelid_turi1`），绕开名实不符的键；清单里给每个键记「实测方向与强度」，不按名字推测。
- **在 Harness 流程里**：本流程尚无形态键实测阶段；方案里引用形态键时注明实测方向与强度的来源，缺实测就写明并交人。
- **适用条件**：Shinano 素体的眼部形态键；其他素体同样要先量。
- **证据等级**：单一案例（候选）

## 量眼部形态键：先按 x 正负分左右眼，再在每只眼里取分位

- **症状**：第一版测量把 `eyelid_turi2` 量成「两侧等量下压」，与看图结论冲突。
- **机制**：按 |x| 的中位数把两只眼的位移顶点劈成「内外侧」，会把颧骨、眉骨这些 |x| 大的顶点混进「外侧」；横向位移 Δx 左右符号相反，跨两眼平均会抵消成 0。
- **判据**：先按 x 的正负分出左右眼，再在每只眼内部按位置取分位；Δx 只在单眼内统计。
- **当时的修法**（人工作业，供理解机制）：按上述口径重测全部眼部键。
- **在 Harness 流程里**：本流程尚无形态键实测阶段；需要测对称部位时写明口径（先分左右再取分位），停下交人。
- **适用条件**：对称部位（眼、眉、嘴角）形态键的顶点级测量。
- **证据等级**：单一案例（候选）
