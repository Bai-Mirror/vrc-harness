# 案例：衣物跟随身体形态键

实际工程中的成功与失败实例，工程身份已匿名。每例固定写症状、机制、判据、修法、适用条件。

## 案例：外套、衬衫、领带带同名胸型键却无人同步，胸型拉满时整片穿出

- **症状**：用户在原始菜单里把胸型拉满，双乳整片从衬衫、外套里穿出。默认胸型（0.31）下几乎看不出来，所以交付时没发现。
- **机制**：衬衫、外套、领带和两个兜帽的网格上都有与身体同名的胸型键，但厂商预制体不带 MA BlendshapeSync，也没有说明书，这些键恒为 0。同名键就是厂商预期你去同步。
- **判据**：驱动两端各跑一态读值；拉满时正面肤色像素：修前 6,822，修后 837。
- **修法**：每件加 MA BlendshapeSync，`ReferenceMesh` 指同一头像根下的身体，逐个绑定件上存在的同名键；普通版与面捕版两个头像根各做一遍；修后 0／默认／1 三档读回逐值相同。开襟外套不挡胸、里面的件已同步的不动；别人调好的固定值件（包带按大胸调为 100）不动。
- **适用条件**：发生在 Rurune 工程的 PLUMARIUM Re-Poppin 上；「同名键无人同步」的检查对所有素体适用。

## 案例：乳贴缺小胸键，身体缩胸后外浮；在 Blender 补键导回后偏了 71 mm

- **症状**：身体胸型 `Breast_small=38` 时，乳贴外浮 4–8 mm（早先按渲图记成「陷进皮肤」，几何实测后更正为外浮）；胸型推到大的一侧时又会陷进皮肤（缺 `Breast_big(limit)`）。
- **机制**：乳贴网格没有身体会被驱动的胸型键。第一次在 Blender 里补键，Blender 内往返核对为 0.000 mm，导回 Unity 后蒙皮却偏了 71 mm：导出的网格空间与 bindpose 和厂商原 FBX 不同（顶点差到米级、bindpose 差 1.27、位移被缩小 100 倍），而渲染器用的是场景里原来的骨骼。
- **判据**：换网格后、身体键为 0 时，新旧网格 `BakeMesh` 的世界坐标逐顶点差 ≈0；三档量距。
- **修法**：在 Unity 里给原网格副本加帧（身体 0／100 各烘一次得位移场 → 最近 4 点反距离加权 → 用蒙皮矩阵的逆换回网格空间 → `AddBlendShapeFrame`），只换 `sharedMesh`，再加 BlendshapeSync。结果 p50 为 1.33 → 1.28 → 1.13 mm（原件在 38 档为 5.74 mm、100 档为 14.48 mm）。
- **适用条件**：发生在 Rurune 工程上；补不补「大胸」一侧由用户拍板。

## 案例：同名键数值失配 38，量距几乎不变，判为无可见后果

- **症状**：跟随检查报某件外套与上衣的键值和身体失配 38。
- **机制**：衣物落在该键几乎不动的区域，键值差不带来几何差。
- **判据**：编辑模式下身体与衣物各按失配的两个值 `BakeMesh`，衣物到身体的 p50 都约为 5.8 mm（上衣 14.5 → 14.1 mm）；变化 < 1 mm，记「无可见后果」。
- **修法**：交付件不动。检查工具的改进方向：跟随判定按「该键在这件衣物区域的位移量」加权。
- **适用条件**：发生在 Rurune 工程上。

## 案例：肩部收缩键在穿衣时读数为 0，冻结 Animator 对照判定有无可见后果

- **症状**：读数显示身体的 `Shoulder_OFF` 在衣服穿着时为 0，而厂商 clip 的本意是 100。
- **机制**：厂商层权重为 0 或写者缺失，这个键从未被写。
- **判据**：关掉头像根的 Animator 冻结后，手设 0／100 各渲一组；正对照只渲身体，差异约 35,000 px／512²。盖在肩部的针织背心要先关掉。第一轮的后视图被头发整个挡住，差 0 毫无意义——隐藏头发、尾巴、挎包后重拍。
- **修法**：穿衣组差 0 或只有零星散点 → 记「待机无可见后果，动作中待查」；差异成片 → 补写者（Shape Changer 挂在衣物上）。
- **适用条件**：发生在 Kipfel 工程上；方法与素体无关。

## 案例：Play 里换网格做对照，量到的距离全是垃圾值

- **症状**：在 Play 里把渲染器的 `sharedMesh` 换成资产里的原网格，比较换前换后，量到的距离全是 100 mm 量级的垃圾值，渲图甚至逐像素不变。
- **机制**：NDMF／AAO 构建后，渲染器的骨骼数组被重排，身体被合进 `$$AAO_AUTO_MERGE_SKINNED_MESH_n`；换回原网格后蒙皮对应关系错乱。
- **判据**：换网格类对照只在编辑模式、用场景里真实的骨骼做；Play 里只做改形态键值的对照。
- **修法**：改在编辑模式 `BakeMesh` 后量衣物到身体的最近距离分位数。
- **适用条件**：发生在使用 Avatar Optimizer 网格合并的 Rurune 工程上；机制与素体无关。
