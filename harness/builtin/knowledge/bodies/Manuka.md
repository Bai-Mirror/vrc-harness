# Manuka：菜单互斥机制相关的素体知识

## Manuka：衣装互斥用 3bitInt（4 组 × 8 档）

- **适用范围**：接手 Manuka 素体的已有工程、需要改动衣装切换时。
- **结论**：见过的 Manuka 工程用 3bitInt 做衣装互斥：4 组 Int 参数、每组 8 档。这类工程的典型失效有两种：生效的控制器与原版或改版控制器并存，改错了那一份；3bitInt 引用的 Int 参数不在活跃头像的参数表里。
- **判据**：先从构建后的控制器确认哪一份控制器在生效、每组 Int 参数被哪些层读取；核对这些 Int 参数都在活跃头像的参数表里。
- **证据等级**：单一案例（候选）
- **失效条件**：工程未使用 3bitInt 时。
