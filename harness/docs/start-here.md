# 开始使用 Harness

Harness 是一个 VRChat 头像制作工作台。你描述想要的角色、附上参考图，并允许它读取你持有的素材；它负责选材、准备工程和推进制作。需要你选择效果或确认重要变化时，会在项目对话中停下来。

## 首次打开

1. 打开 Harness，按引导选择工作区和产出目录。
2. 在环境检查中安装缺少的组件。Unity 许可证需要你在 Unity Hub 中激活；脸型设计需要 Blender，可在环境页安装。
3. 在 AI 连接中选择提供方并填写自己的 Key。DeepSeek 默认使用 `deepseek-flash`；GLM 默认使用 `glm-5.3-flash`。
4. 在素材页授权自己的素材目录。目录授权允许读取和选材；制作使用项目副本。

模型请求会使用你的账户额度。收费、登录和安装许可由相应提供方管理；请使用有权使用的素材。

## 发起制作

新建一个头像项目，在对话中写下目标并添加图片。例如：“参考这张图，帮我做一个 VRChat 角色，给我能继续编辑的工程。”无需提供工程模板。模板与技术配置位于高级选项。

查看 AI 给出的方向，选择你希望继续的方案。制作开始后，项目会显示当前进展和需要你决定的事项。脸型候选应查看真实正面、侧面对照；没有实际图片的记录不代表效果已通过。

## 中断与继续

制作中断时，原要求、素材和已有记录会保留。使用项目中的“核对并继续制作”；Harness 先确认执行结果，再决定如何继续。服务离线时先恢复服务，然后刷新页面。取消制作也会先确认执行已停止。

不要把“检查通过”当作最终视觉效果已接受。交付前仍需确认实际效果，并在 VRChat 中进行客户端测试。

## 测试版状态

`0.1.0-dev.1` 当前仍是待发布候选。上一候选的 Windows 与 Linux 完整检查已有通过记录，新版生产修复仍待同源复验。原图端到端产出、两套真实头像的完整交付及真人注意力测量仍未完成，不能据此宣称稳定自动改模。

产品改进数据默认关闭。在设置中明确加入后，才会按说明回传结构化报告；退出可取消未上传队列并撤回未采用的数据。私人素材、图片、原始对话和 Key 不属于默认报告。
